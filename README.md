# 🚀 Muhammad Ridho Hafidz - Portfolio Website

## 📋 Overview

Professional portfolio website showcasing expertise in **System & Cloud Engineering**, infrastructure operations, and DevOps practices. Built with modern web technologies for optimal performance and user experience.

## 🌟 Features

### ✨ **Design & UI/UX**
- **Responsive Design** - Optimized for desktop, tablet, and mobile devices
- **Modern Gradient Design** - Eye-catching visual aesthetics
- **Smooth Animations** - CSS3 and JavaScript-powered interactions
- **Professional Typography** - Clean, readable font hierarchy
- **Dark/Light Theme Support** - Accessible color schemes

### 🔧 **Technical Features**
- **Semantic HTML5** - Properly structured markup
- **CSS Grid & Flexbox** - Modern layout techniques
- **Vanilla JavaScript** - No external dependencies
- **Performance Optimized** - Fast loading times
- **SEO Friendly** - Meta tags and structured data
- **Print Stylesheet** - Professional print layout

### ♿ **Accessibility**
- **WCAG 2.1 Compliant** - Accessible to all users
- **Keyboard Navigation** - Full keyboard support
- **Screen Reader Friendly** - Proper ARIA labels
- **High Contrast Support** - Enhanced readability
- **Reduced Motion Support** - Respects user preferences

## 🛠️ Technologies Used

- **HTML5** - Semantic markup
- **CSS3** - Modern styling with Grid, Flexbox, and Custom Properties
- **Vanilla JavaScript** - Interactive features
- **Font Awesome** - Professional icons
- **Google Fonts** - Typography enhancement
